整数平衡化工具（Windows 64 位）
==============================

使用方法
--------
1. 将压缩包完整解压到一个文件夹。
2. 双击“整数平衡化.exe”。程序会在浏览器中打开本地网页。
3. 输入非负十进制整数，选择等号数量和规则，点击“判断并生成方案”。
4. 使用结束后，关闭运行程序的终端窗口即可。

如果浏览器没有自动打开，请把终端中显示的 http://127.0.0.1:端口/
地址复制到浏览器。此版本不需要另行安装 Python，也不需要联网。

功能说明
--------
- 默认寻找恰好一个等号的方案，也可允许多个等号。
- 默认规则允许每段首个数词带前导负号；严格规则禁止这种负号。
- 默认请求 5 条不同等式，最多请求 20 条；实际数量可能少于请求数量。
- 所有展示的等式都保留原数字与顺序，并通过精确分数验证。
- 输入最长 256 位，不接受负数、小数、多位先导零或科学计数法。
- 搜索超时或达到资源上限时，会显示未完成状态，不会据此报告无解。
