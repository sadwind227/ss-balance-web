# Windows 打包记录

日期：2026-10-08。

## 交付物

- `dist/整数平衡化-Windows-x64.zip`：完整发布包，解压后双击 `整数平衡化.exe`。
- `dist/整数平衡化/`：与压缩包内容相同的解压目录，供本机直接使用。
- 发布包包含 `README.txt` 和上游 `LICENSE`，用户无需另装 Python。
- ZIP 大小：10,439,693 字节；SHA-256：`9032597abe24f9ad1d9ef2e0da7cba226b7d6fb49932b027ed1fb1327924436a`。

采用 PyInstaller 6.22.3、Python 3.14.7 构建 Windows x64 文件夹版。单文件版在当前环境测试时因运行时临时目录无法写入而失败，因此交付文件夹版。发布包中包含程序运行需要的 Python 运行时和数据，构建工具未包含其中。

## 构建与实际验证

构建命令：

```powershell
python tools/install_build_deps.py
python tools/build_release.py
```

测试时，从最终 ZIP 重新解压到独立目录，运行其中的 `整数平衡化.exe`，并检查：

| 输入 | 打包程序的结果 |
|---|---|
| `1234`，默认规则 | 3 条已验证方案，含 `12=3 * 4` |
| `222`，允许多个等号 | `2=2=2` |
| `9989858`，允许多个等号 | 无解 |
| `1234567890123456`，严格规则 | 3 条已验证的单等号方案 |

解压包里的服务成功启动并返回网页与任务接口，后台计算子进程也实际运行成功。此包仅针对 Windows 64 位；其他平台可从源码运行。
