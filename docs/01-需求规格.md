# 需求规格

版本：规划稿 v0.1；日期：2026-10-08。

## 1. 产品目标

输入一个整数后，回答它是否能够平衡化，并给出可核验、可复制的若干等式。一个输入对应多种方案；第一版不包含批量上传整数列表。

每条等式必须保留原数字串的全部数字及顺序，每个数字恰好使用一次，只能插入规定符号。相邻数字可以拼接成多位数，例如 `1234 → 12=3*4`。

## 2. 输入范围

- 第一版接受非负十进制整数，以文本传输与处理。
- 接受 `0` 和单个数字，并说明无法插入等号形成两个非空数字段。
- 去除首尾空白；多位数不接受先导零，以保持与上游整数数据一致。
- 不接受负整数、小数、科学计数法、千位分隔符或内部空白。对负整数的推广留待另行定义。
- 第一版输入上限暂定 256 位，作为产品与资源限制，不是定理的适用上限。
- 不把整个输入转换为 JavaScript Number，避免大整数丢失精度。

## 3. 数学规则

允许符号：`+ - * / ( ) =`，禁止除以零。

默认使用上游 `segment` 规则：每个等号分割段的第一个数词可以带前导负号，例如 `(-1)+4=3=3`。不允许任意位置的一元负号，也不把 `-(整个表达式)` 当作段首负数词。

提供严格规则 `strict`：只允许二元加减乘除与括号，不允许前导负号。

提供两种等号设置：

| 设置 | 含义 |
|---|---|
| 恰好一个等号（默认） | 寻找两段表达式值相等的方案，与主定理对应 |
| 允许多个等号 | 优先给出一个等号的方案，必要时继续寻找链式等式 |

不在普通界面使用容易混淆的“强不可平衡／弱不可平衡”术语，改为说明“一个等号无解”或“多个等号有解”。

## 4. 判定与搜索结果

“是否存在方案”和“当前是否生成了方案”分开记录。

| 对用户显示的情况 | 必须具备的依据 |
|---|---|
| 可以平衡化 · 已找到若干方案 | 至少一条方案通过独立验证 |
| 可以平衡化 · 正在生成方案 | 适用规则下的已核验分类数据或项目定理能证明存在性 |
| 按当前规则无法平衡化 | 适用规则的完整反例数据，或已经完成的精确穷举 |
| 搜索尚未完成 | 当前证据不足以判定，且计算达到资源限制或被取消 |

超时、内存限制、单段长度限制、保留表达式数量限制、段数限制，均不能单独作为“无解”的依据。

当引用主定理判定存在性时，结果依据标为“依据项目定理”；当获得等式时，标为“已验证方案”。这一区别对用户可见。

## 5. 多方案功能

- 默认请求 5 个不同方案，允许选择 1–20 个。
- “请求 5 个”不意味着一定有 5 个不同方案。实际找到多少，就显示多少。
- 优先一个等号、运算较少、括号较少的方案。
- 去掉仅空格不同或冗余括号不同的重复方案；默认不把等式两边整体取负当作额外方案。
- 保留结构不同的合法方案；不宣称列出了全部方案或全局最简方案。
- 每条显示等式、共同值、等号数量，并提供复制按钮。
- 运算符采用 `* /` 作为标准可复制格式；显示层可同时提供 `× ÷` 阅读形式。
- 若只找到一个方案，直接显示一个，不拼凑重复结果。

## 6. 页面功能

页面以一个输入区和一个结果区为主，不需要注册、登录或联网提交。

输入区包含整数、规则、等号设置、目标方案数量。“判断并生成方案”启动计算；计算中可以取消，并保留已经验证的方案。

结果区包含判定、依据、方案列表和必要的限制提示。更详细的搜索用时与资源限制放入可展开的详情，不堆在主流程中。

不显示无法可靠估计的完成百分比；使用“正在查表”“正在寻找方案”等阶段状态。

## 7. 代表性验收案例

| 输入／设置 | 应达到的行为 |
|---|---|
| `1234`，一个等号 | 至少产生一条正确方案，例如 `12=3*4` |
| `1919810` | 至少产生一条正确方案，例如 `19-1=9+8+1+0` |
| `113` | 判定无解，依据明确 |
| `222`，一个等号 | 判定一个等号无解 |
| `222`，允许多个等号 | 产生 `2=2=2` 或等价合法方案 |
| `9989858` | 按上游规则判定无解 |
| `9989859` | 判定存在一个等号的方案；见证生成的耗时在性能阶段实测 |
| `1433`，默认规则／多个等号 | 可接受 `(-1)+4=3=3` |
| `1433`，严格规则 | 不得输出上述含前导负号的方案；重新按严格规则判定 |
| 至少 16 位的整数 | 使用构造路径输出已验证的单等号方案 |
| `0`、`7` | 说明数字不足以形成等式，不调用昂贵搜索 |
| `00123`、`-123`、`1e10` | 输入提示清楚，不静默修改数学含义 |
| 搜索取消或达到上限 | 保留已有结果，未完成搜索不得误报无解 |

第一版性能指标在实测后确定；不预先承诺所有 8–15 位输入都能在几秒内生成多条方案。
