## 已由用户确定

- 目标：判断整数能否平衡化，并自动给出若干合法等式。
- 产品形态：本地网页＋Python 运算引擎。
- 第一阶段只写工程文件与计划；第二阶段已获授权制作应用。

## 规划默认值，可在实施前调整

| 项目 | 默认选择 | 理由 |
|---|---|---|
| 规则 | `segment` | 对应上游发布的多等号数据，同时提供严格模式 |
| 等号数量 | 恰好一个 | 对应主定理；允许多个等号作为可选设置 |
| 请求方案数 | 5，最多 20 | 兼顾可读性和搜索资源，不承诺一定找到请求数量 |
| 第一版输入 | 非负十进制，最多 256 位 | 避免未定义负整数规则，控制资源与展示长度 |
| 数学计算 | 精确有理数 | 避免近似相等造成错误等式 |
| 前端 | 原生 HTML／CSS／JavaScript | 第一版界面较简单，便于离线分发 |
| 服务 | Python 标准库优先，独立进程计算 | 复用上游并支持取消，不让计算阻塞页面 |
| 分发 | 先可运行本地目录，后桌面打包 | 先验证数学功能与性能 |

## 上游资料

- [项目首页与 README](https://github.com/guijixzh/Silicon-Silence-s-Balance-Integer-Theorem-Proof-and-Verification-Program)
- [核心计算代码 sst_core.py](https://github.com/guijixzh/Silicon-Silence-s-Balance-Integer-Theorem-Proof-and-Verification-Program/blob/main/sst_core.py)

上游说明中的关键结论：

- 大于 `9989858` 的整数均能用一个等号平衡；该整数本身为不可平衡反例。
- 不可归零串 2873 条，最长 7 位；素可归零串 6534 条，包含 `0`。
- 2–7 位单等号反例 19515 条；默认规则下完全无解 18198 条，多等号有解 1317 条。
- 默认规则允许每段第一个数词带前导负号；严格规则禁止此负号。
- 原始完整证明文稿未包含在仓库中；仓库还声明主体代码与文本由 AI 生成，经过人工初步核查。

这些条目是上游报告的结论。本阶段未实际运行数据验证，不把它们标记为本项目独立证明的结果。

2. 检查筛选完整性；默认验证或 `--deep` 的逐条检查不能自动替代完整候选空间检查。

5. 验证素可归零索引在所有 8 位窗口中的覆盖，并生成可复用的严格归零见证。
6. 对上游单见证结构进行扩展，同时保证无解判定不会因优化截断而失真。
